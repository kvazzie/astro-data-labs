The Author thesis

Artemii Rachev is exploring the position that web projects benefit from a monorepository with Astro as their web foundation. The Lab puts that evolving thesis to the test through working experiments.

Each Experiment investigates one possible approach. Contributors can disagree with the thesis, and every team retains its own architecture decisions.

Content collections / SQL visibility

Exploring

DuckDB content inspector

Can Astro's generated content store provide SQL visibility for inspecting collections, schema drift, and references during a Content-first launch?

A read-only Direct data view of Astro content. Load the bundled sample or a local store, start DuckDB in the browser, and inspect collections with SQL.

Observable result
The sample has seven ordinary entries: authors = 2, blog = 3, docs = 2. Queries inspect titles, field coverage, and references.
Current limits
Exploring means the question and implementation are still changing. This Experiment reads Astro's internal generated store, which can change. Selected content stays in tab memory.
